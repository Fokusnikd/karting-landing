# Картинг «Поворот направо» — демо-лендинг

Демо-проект для портфолио: лендинг крытого картодрома. Клуб вымышленный, имена, цены и время кругов придуманы, форма никуда не отправляет данные.

## Моушн-графика

- Первый экран: заголовок «въезжает» со скосом, по SVG-трассе едут три карта, по траектории бежит световой след
- Трасса, привязанная к прокрутке: траектория рисуется, карт проезжает круг, подсвечиваются секторы, тикает время круга
- Таблица рекордов в «прямом эфире»: пилоты улучшают время, строки плавно перестраиваются
- Счётчики, бегущая строка, анимация карточек тарифов и шагов
- Всё уважает `prefers-reduced-motion`: при уменьшенном движении анимации отключаются, контент остаётся

## Функциональность

- Тарифы подставляются в форму записи, цена пересчитывается от числа пилотов
- Запись: выбор дня и времени (занятые слоты недоступны), маска телефона, валидация

## Стек

React 19, TypeScript, Tailwind CSS 4, Motion, Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`. Пути относительные — сборку можно выложить в любую папку, например на GitHub Pages.
